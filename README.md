# Pixzl Homebrew Tap

Offizieller Homebrew-Tap von [Pixzl](https://www.pixzl.de).

## Installation

```sh
brew install --cask pixzl/tap/dockpin
```

## Casks

| Cask | Beschreibung |
|------|--------------|
| [`dockpin`](Casks/dockpin.rb) | [DockPin](https://www.pixzl.de/apps/dockpin) — hält das macOS-Dock dauerhaft auf einem gewählten Bildschirm. |
